# 센둥이 시뮬레이터

아이돌 그룹 리센느(RESCENE)와 관련된 컬렉션 북 · 시뮬레이터 · 계산기를 모은 사이트입니다.

사이트: https://scene-simulation.github.io/

## 무엇이 있나요

- **포카 컬렉션 북** — 콜라보 포토카드를 얼마나 모았는지 기록합니다. CU 리센느 405빵 · 할리스(HOLLYS) · 나랑드 · 도미노 콜라보, 포토카드 전체보기
- **굿즈 컬렉션 북** — 더현대 팝업 스토어 · 크림(KREAM) 티셔츠 등 굿즈 보유 기록, 굿즈 전체보기
- **장난감**
  - **포토카드 뽑기 시뮬레이션** — 콜라보를 골라 모든 종류를 모을 때까지 드는 비용을 시뮬레이션하고 그래프로 분석합니다
  - **뽑기 미니게임** — 원하는 카드 한 장이 몇 번 만에 나오는지 도전합니다
  - **조회수 예측기** — 유튜브 채널 영상의 조회수를 15분마다 모아 게시 후 24시간 · 7일 · 30일 조회수와 다음 100만 단위 돌파 시점을 예측하고, 지난 예측을 채점합니다
  - **예측의 신** — 즐겨찾기한 영상이 다음 100만 단위를 넘는 때를 직접 맞혀 보고, 실제 기록으로 채점합니다
- **위시리스트 · 영상 즐겨찾기**
- **기록 백업** — 이 브라우저에 저장된 기록 전부를 파일 하나로 저장하고, 그 파일로 되살립니다

컬렉션 기록 · 위시리스트 · 즐겨찾기 · 예측 기록은 모두 **이 브라우저(localStorage)에만** 저장됩니다. 서버로 보내지 않으며, 다른 기기와는 이어지지 않습니다.
사이트가 업데이트되어도 기록은 그대로 남습니다. 다만 인터넷 기록을 지우거나 기기 · 브라우저를 바꾸면 사라지니, 가끔 **기록 백업**으로 파일을 저장해 두세요. 백업 파일로 다른 기기에 옮길 수도 있습니다.
조회수 예측은 비전문가가 만든 계산식이므로 재미로만 참고해 주세요.
