# 센둥이 시뮬레이터

리센느 포토카드 뽑기 시뮬레이터와 실물 컬렉션 북.

- **장난감 › 포토카드 뽑기 시뮬레이션** — 콜라보 포토카드를 뽑아 모든 종류를 모을 때까지 드는 비용을 시뮬레이션하고, 분석 화면에서 그래프로 보여 줍니다. 뽑기 종류(콜라보)를 골라서 뽑을 수 있고, **뽑기 미니게임**에서는 카드 한 장을 골라 몇 번 만에 나오는지 도전합니다.
- **컬렉션 북 › 2026 › CU 리센느 405빵 콜라보** — 실제로 산 빵과 모은 카드를 기록합니다. 기록은 브라우저(localStorage)에 저장됩니다.
- **장난감 › 조회수 예측기** — 유튜브 영상의 조회수·좋아요·댓글 흐름으로 24시간·7일·30일 조회수를 세 가지 공식으로 예측하고, 오차 범위와 적중률(성적표)을 보여 줍니다. 실제 수치 수집기를 연결하기 전까지는 예시 데이터로 표시됩니다.
- 준비 중: 나랑드 콜라보, 도미노 콜라보

사이트: https://scene-simulation.github.io/

## 수정 방법

`index.html`은 `tools/`의 파일로 만들어집니다.

- `tools/source.html` — 원본 페이지(405빵 카드 데이터 · 컬렉션 북)
- `tools/gacha.js` — 포토카드 뽑기 시뮬레이터 (뽑기 · 분석 · 뽑기 미니게임 화면)
- `tools/views.js` — 조회수 예측기 (예측 공식 · 성적표). 기록은 `data/views.json` 에서 읽고, 비어 있으면 예시 데이터를 씁니다
- `tools/theme.css` — 디자인
- `tools/shell-top.html`, `tools/shell-bottom.html`, `tools/shell.js` — 사이드바, 홈 화면, 메뉴 이동

```
node tools/build.js tools/source.html index.html
```
